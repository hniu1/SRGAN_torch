# Ready-to-use climate downscaling skills

| Skill | Use it for |
|---|---|
| [`climate-downscaling`](climate-downscaling/SKILL.md) | Validate inputs and run Stage 1, Stage 2, or cascade inference |
| [`climate-downscaling-evaluation`](climate-downscaling-evaluation/SKILL.md) | Evaluate checkpoints, summarize metrics, and produce standard spatial plots |
| [`climate-downscaling-ops`](climate-downscaling-ops/SKILL.md) | Prepare/train models and inspect or operate Frontier Slurm jobs |

Each child directory is a self-contained installable skill. The framework-neutral source package for teams authoring their own variants is in [`../skill-authoring-kit`](../skill-authoring-kit/README.md).
