# Ready-to-use REFINE skills

REFINE stands for **Resolution-Enhancement Framework Integrating Artificial
Intelligence for Natural and Energy System**.

| Skill | Use it for |
|---|---|
| [`refine-downscaling`](refine-downscaling/SKILL.md) | Validate inputs and run single-stage 6× inference |
| [`refine-evaluation`](refine-evaluation/SKILL.md) | Evaluate checkpoints, summarize metrics, and produce standard spatial plots |
| [`refine-ops`](refine-ops/SKILL.md) | Prepare/train models and inspect or operate Frontier Slurm jobs |

Each child directory is a self-contained installable skill. The framework-neutral source package for teams authoring their own variants is in [`../skill-authoring-kit`](../skill-authoring-kit/README.md).
