# Map boundaries

The two GeoJSON files in this directory come from the Natural Earth 1:50m
cultural-vector dataset:

- `ne_50m_admin_0_countries.geojson`
- `ne_50m_admin_1_states_provinces.geojson`

Natural Earth data are in the public domain. The files were obtained from the
official Natural Earth vector repository maintained at
https://github.com/nvkelso/natural-earth-vector.
